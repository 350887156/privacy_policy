AuraRead 隐私政策

最后更新日期：2026 年 11 月 11 日 生效日期：2026 年 11 月 11 日

📱 引言

AuraRead（「我们」）是一款本地电子书阅读工具。我们致力于保护您的隐私。本隐私政策说明您使用 AuraRead 应用程序（以下简称「本应用」，Bundle ID：com.aura.reader）时，我们如何收集、使用、存储和保护相关信息。

重要说明：

  • 本应用不会主动收集您的姓名、电子邮件、电话号码等可直接识别个人身份的信息，也不需要注册或登录。
  • 您导入的书籍文件、阅读进度、笔记与统计等数据默认仅存储在您的设备本地，我们不运营用于存储您书库的服务器。
  • 只有在您主动开启「iCloud 同步」或使用 Apple Watch 阅读时，相关数据才会通过 Apple iCloud 或 Apple Watch 连接在您自己的设备之间传输；数据存放在您的 Apple 账户空间内，我们无权访问。
  • 为改进产品体验，在您可在设置中关闭的前提下，我们通过 友盟+ 移动统计 SDK 收集去标识化的使用统计数据（详见下文）。我们不会通过该服务上传书籍正文、章节内容、书名或文件名等书库内容。

🔍 我们收集的信息

1. 不收集的个人信息

本应用不会由我们主动收集或要求您填写以下信息：

  • ❌ 姓名
  • ❌ 电子邮件地址
  • ❌ 电话号码
  • ❌ 精确地理位置
  • ❌ 通讯录、照片图库（除您主动通过系统文件选择器导入书籍外）
  • ❌ 面部图像、深度图、面部网格、虹膜或 Face ID 数据（闭眼翻页仅读取眼部闭合系数，详见 3.5 节）

说明：若您开启数据分析，友盟统计 SDK 可能按友盟隐私政策收集设备标识符（如 IDFV）、IP 地址、网络类型、应用版本与功能使用事件等去标识化技术信息。本应用未请求 App Tracking Transparency 授权，不将 IDFA 用于跨 App 追踪。您可随时在 设置 → 启用分析 中关闭。

2. 仅存储在你设备本地的数据

本应用仅在您的设备本地存储以下数据：

数据类型 用途 存储位置 保留期限
书籍文件 阅读 TXT、EPUB、MOBI、AZW/AZW3、PDF、CBZ 等格式 应用沙盒 Documents/Books 直到您删除该书
书架与元数据 书名、作者、封面、章节、分类、阅读位置 本地 Core Data 直到您删除该书或卸载应用
笔记、标注与书签 划线、批注、书签 本地 Core Data 直到您删除该条记录或卸载应用
阅读会话记录 阅读时长、阅读天数、热力图、时段分布等统计 本地 Core Data 直到您清除统计或卸载应用
阅读设置 字体、字号、主题、翻页动画、排版等偏好 本地 Core Data / UserDefaults 直到您修改或卸载应用
应用设置 外观、语言、分析开关等 本地 UserDefaults 直到您修改或卸载应用
缓存数据 分页结果、章节文本、封面缩略图、EPUB 内嵌图片、小组件快照 应用沙盒 Caches / App Group 系统或应用可随时清理

说明：上述数据由您使用本应用产生或导入；除下文「网页导入」「iCloud 同步」「Apple Watch 同步」所述情形外，我们不会从您的设备取走这些数据。

3. 你主动开启后跨设备同步的数据（iCloud）

iCloud 同步默认关闭，仅在您于 设置 → iCloud 同步 中打开总开关后才生效。您可分别控制：

同步项 内容 默认状态（总开关开启后）
阅读进度同步 阅读位置、书签、笔记与标注 开启
书籍文件同步 书籍文件与封面 关闭
冲突策略 多设备冲突时的取舍方式（如以云端为准 / 以本机为准） 由您选择
  • 存储位置：阅读进度、书签、笔记与标注通过 iCloud 键值存储（NSUbiquitousKeyValueStore）同步；书籍文件通过 iCloud Drive 容器（iCloud.com.aura.reader）同步，可在「文件」App 的 iCloud 云盘中查看。
  • 数据控制：上述数据存放在您自己的 iCloud 账户中，由 Apple 按其隐私政策存储与加密；我们无权访问、读取或恢复。
  • 关闭与删除：关闭同步开关后，应用停止新增同步，但不会自动删除已同步到 iCloud 的数据；如需删除，请在系统 iCloud 管理或「文件」App 中删除对应数据。
  • 无自建服务器：我们不会把同步数据抄送到自己的服务器，也不提供云端书库服务。

4. 同步到 Apple Watch 的数据

当您安装 AuraRead 的 Apple Watch App 并使用手表阅读时，本应用会通过 WatchConnectivity 与 App Group 将以下数据传输到与您 iPhone 配对的 Apple Watch：

  • 书库快照（书名、作者、封面、格式等元数据）
  • 书籍正文分块
  • 阅读进度与阅读设置

这些数据仅存储在您的 iPhone 与手表本地，传输由 Apple 系统框架完成；我们无权访问。取消手表同步或删除手表 App 后，手表端数据随之删除。

🛠 我们使用的技术与权限

3.1 文件导入（文件 App / 共享 / 打开方式）

您可通过系统文件选择器、其他 App 的「共享」或「用 AuraRead 打开」将电子书导入本应用。导入的文件将复制或保存到本应用沙盒内，仅用于在本机阅读。

3.2 网页导入（本地网络 / WebDAV / SMB）

在 设置 → 网页导入 中，本应用可在您的 iPhone / iPad 上启动本地 HTTP 服务（基于开源库 GCDWebServer），以便在同一 Wi‑Fi 下的电脑浏览器中上传书籍；本应用也支持通过 WebDAV 或 SMB 从局域网服务器导入书籍。

项目 说明
网络范围 仅限您设备所在的本地局域网；不连接我们的云端服务器
数据传输 上传的文件直接写入本机书库，不经由我们中转
系统权限 「本地网络」权限（NSLocalNetworkUsageDescription）；Bonjour 服务类型 _http._tcp
账号信息 WebDAV / SMB 的服务器地址与用户名保存在本机偏好设置，密码保存在系统钥匙串（Keychain），不上传
使用注意 服务仅在您开启网页导入且应用保持前台时运行；离开相关页面后服务停止

数据流向：仅在您的局域网内、在您的设备与您的电脑或服务器之间传输；我们无从访问。

3.3 iCloud 同步（你主动开启）

见上文「3. 你主动开启后跨设备同步的数据（iCloud）」。同步由 Apple iCloud 提供，我们不运营任何同步服务器，也无法读取您的 iCloud 数据。

3.4 Apple Watch 同步（你主动开启）

见上文「4. 同步到 Apple Watch 的数据」。传输由 Apple WatchConnectivity 完成，我们无法读取手表或 iPhone 上的数据。

3.5 面容数据（TrueDepth / ARKit）

AuraRead 的「闭眼翻页」功能使用 Apple ARKit 的面部追踪（ARFaceTrackingConfiguration）读取原深感摄像头（TrueDepth）提供的面部表情系数，仅用于判断您是否闭眼以触发翻页。

项目 说明
收集的信息 仅实时读取左右眼闭合程度（blendShapes 中的 eyeBlinkLeft / eyeBlinkRight 数值）
不收集的信息 不采集面部图像、深度图、面部网格、虹膜或 Face ID 数据；不生成面部模板、面部标识或任何生物特征标识；不进行身份识别
使用目的 仅在您主动开启「闭眼翻页」并停留在阅读页面时，判断闭眼动作并翻至下一页
处理方式 全部在设备端由 ARKit 实时处理；逐帧数值仅在内存中用于阈值判断，判断完成后立即丢弃
存储位置 不存储。不写入磁盘、不上传服务器、不进入 iCloud、不进入日志或任何统计 SDK
保留期限 无。因不留存任何面部数据，故不存在保留期限
共享 不与任何第三方共享；不用于广告、分析或用户画像
关闭与删除 关闭「闭眼翻页」、离开阅读页或应用进入后台时，AR 会话立即停止；由于不存储任何数据，无需额外删除操作
权限 首次开启时请求相机权限；若拒绝，开关自动回退关闭，可随时在系统设置中修改
适用设备 需配备原深感摄像头的 iPhone / iPad；不支持的设备会提示并保持开关关闭

3.6 App 锁（Face ID / Touch ID）

您可选择开启 App 锁，使用系统 Face ID / Touch ID 解锁本应用。生物识别由 iOS 的 LocalAuthentication 与安全隔区（Secure Enclave）完成，本应用只接收验证成功或失败的结果，无法读取您的面部或指纹数据，也不会将其上传或存储。您可随时在设置中关闭 App 锁。

3.7 实时活动、小组件与听书

  • 实时活动 / 灵动岛：阅读时可在锁屏与灵动岛显示当前书名与阅读进度。数据仅保存在本机，关闭阅读或结束活动后停止展示。
  • 小组件：桌面与锁屏小组件通过 App Group 读取本机的阅读进度快照，不上传服务器。
  • 听书（TTS）：使用系统 AVSpeechSynthesizer 在设备端合成语音；部分系统音色需由 iOS 自行下载。书籍文本不会上传至我们的服务器。

3.8 阅读提醒通知

您可开启阅读提醒。提醒由本地通知实现（UNUserNotificationCenter），不经过任何推送服务器；通知权限可随时在系统设置中关闭。

3.9 开源组件（设备端处理）

本应用使用以下第三方库，均在设备本地解析或提供服务，不将您的书库内容发送至开发者服务器：

  • GCDWebServer：局域网网页上传
  • ZIPFoundation：EPUB 等压缩包解析
  • Kanna：HTML/XML 解析

3.10 我们当前未使用的功能

截至本政策生效日，本应用未提供且未启用：

  • ❌ 账号登录与由我们运营的云端书库
  • ❌ 推送通知营销
  • ❌ 内置书城或内容分发
  • ❌ 第三方广告与跨 App 追踪

📖 关于您导入的内容

本应用不提供任何受版权保护的电子书内容。所有书籍均由您自行导入。您应确保对所导入内容拥有合法使用权。我们不对用户导入的内容负责，也无法访问或审查您设备上的书库。

🔒 数据安全

  1. 设备安全：请使用密码、Face ID 或 Touch ID 保护您的设备；可另行开启 App 锁。
  2. 沙盒隔离：应用数据存储在 iOS 沙盒中，其他应用无法直接读取。
  3. 本地网页导入：仅在您主动开启时监听局域网；建议在可信 Wi‑Fi 环境下使用，用毕关闭服务。
  4. iCloud 同步与备份：同步与备份数据由 Apple 按其安全机制加密传输与存储；我们无权访问。
  5. 手表数据：仅存储在与您配对的 Apple Watch 本地，由系统加密保护。
  6. 无自建服务器：我们没有存储您书库的服务器，因此不存在因我方服务器泄露而导致书库外泄的风险。

👶 儿童隐私

本应用为通用阅读工具，不面向不满 14 周岁的儿童主动收集个人信息。本应用不展示第三方广告，不收集儿童姓名、联系方式等个人信息。若您为监护人并认为孩子向我们提供了信息，请通过下文联系方式与我们联系。

🌍 数据跨境传输

  • 书库与阅读数据：默认仅存于您的设备，我们不做跨境传输。
  • iCloud 同步（若开启）：数据存储于您的 iCloud 账户，可能由 Apple 按其隐私政策传输至您所在国家/地区以外的数据中心。
  • Apple Watch 同步：仅在您的 iPhone 与手表之间传输，不经过我们的服务器。
  • 友盟统计 SDK（若开启）：数据存储于中华人民共和国境内服务器，适用 友盟+ 隐私政策。
  • 网页导入 / WebDAV / SMB：仅在您的本地网络内传输，不经过我们的服务器。
  • Apple 服务（如 iCloud 备份、App Store）：适用 Apple 相关政策，可能涉及境外数据中心。

📝 您的权利

根据适用的隐私法律（如 GDPR、CCPA、中国《个人信息保护法》），您享有以下权利：

1. 访问权

您可在应用内查看书架、阅读进度、笔记与统计信息；iCloud 同步数据可在您的 iCloud 账户中查看。

2. 删除权

  • 删除单本书籍：在书架中删除，同时会删除该书在本机的进度、笔记与缓存。
  • 删除 iCloud 同步数据：关闭 设置 → iCloud 同步 后，在系统 iCloud 管理或「文件」App 中删除对应数据；关闭开关本身不会自动删除已同步数据。
  • 删除手表数据：取消手表同步或删除手表 App。
  • 删除全部本地数据：卸载本应用，或使用系统「设置 → 通用 → iPhone 储存空间」清除应用数据。

3. 撤回同意

  • 分析数据：随时在 设置 → 启用分析 中关闭友盟统计上报。
  • iCloud 同步：随时在 设置 → iCloud 同步 中关闭总开关或分项开关。
  • 相机 / 面容数据：关闭「闭眼翻页」即停止 AR 会话，并可在系统设置中撤销相机权限。
  • Face ID：关闭 App 锁或撤销系统 Face ID 授权。
  • 本地网络：在 设置 → 隐私与安全性 → 本地网络 中关闭 AuraRead 的权限；网页导入 / WebDAV / SMB 将无法使用，但不影响已导入书籍的本地阅读。
  • 通知：在系统通知设置中关闭阅读提醒。

4. 数据可携带权

您导入的书籍文件存储于应用沙盒；可通过文件共享或重新导出（视系统功能而定）自行备份。iCloud 中的书籍文件可在「文件」App 中直接访问与导出。
